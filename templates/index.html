How the System Works

Four optimized steps executing at 30+ frames per second in your browser

1. Video Capture

Captures video frames in real time from any standard webcam without requiring external sensors.

2. 3D Landmark Extraction

MediaPipe detects 21 hand joints, normalized for scale, distance, and screen translation invariance.

3. Deep Learning Prediction

Deep Multilayer Perceptron with Batch Normalization classifies the posture with 100% verified test accuracy.

4. Text & Speech Output

Temporal smoothing accumulates letters into sentences and vocalizes them via the Web Speech API.

Project Specification

About SignFlow AI

SignFlow AI is an end-to-end Deep Learning and Computer Vision application designed to solve the communication gap between hearing/speech-impaired individuals and non-signers.

Project Objectives
  • Provide real-time sign language gesture recognition without expensive gloves or depth cameras.
  • Achieve translation invariance and scale invariance across different camera setups and lighting conditions.
  • Implement automatic sentence formulation with intelligent debouncing to prevent letter spamming.
  • Offer two-way accessibility through Speech Synthesis (TTS) and Text-to-Sign visual learning.
Technology Stack
Python 3.13 TensorFlow & Keras MediaPipe Hands (Tasks API) OpenCV Flask REST Backend Web Speech API (TTS) Bootstrap 5 & Vanilla JS

Deep Learning Model & Feature Engineering

Raw pixel coordinates fail when a user moves closer or further from the camera. SignFlow AI implements a mathematically rigorous 76-dimensional geometric invariant feature extraction pipeline:

1. Translation Invariance
Subtracts the wrist coordinate $(x_0, y_0, z_0)$ from all 21 keypoints. The hand is always centered at origin.
2. Scale Invariance
Divides relative coordinates by the maximum Euclidean norm $\max_i \|P_i - P_0\|$, guaranteeing identical features at any distance.
3. Geometric Distances
Computes 13 critical fingertip-to-wrist, adjacent tip, and thumb-to-tip Euclidean spans to accurately distinguish similar hand poses.
Neural Network Topology:
Input(76) → Dense(256) → BatchNorm → ReLU → Dropout(0.30) → Dense(128) → BatchNorm → ReLU → Dropout(0.25) → Dense(64) → BatchNorm → ReLU → Dropout(0.20) → Dense(19, Softmax)
